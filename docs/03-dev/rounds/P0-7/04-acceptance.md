- [ ] 详情页上**同时**有「开始服务」（醒目主按钮）与「取消接单」（次要按钮）。
- [ ] 点「开始服务」**不会立刻提交**：先出现一段确认说明与「再想想 / 确认开始服务」两个按钮。
- [ ] 确认说明里明确点出**开始服务之后不能取消接单**（这是一扇单向门）。
- [ ] 点「确认开始服务」之后：状态从**「已接单」变成「护航中」**。
- [ ] 页面上**「开始服务」与「取消接单」两个入口一起消失**。
- [ ] **不需要重新登录、也不需要退出再进这一页**（页面自己更新）。
- [ ] 状态区多出一行**「开始服务时间」**，且「接单时间」**仍然在**、值**没有变**。
- [ ] ⚠️ 反例检查：若「取消接单」还留在页面上，**报告，不要接受**——`serving` 不允许打手普通主动取消。
